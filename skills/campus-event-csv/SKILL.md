# 校园活动 CSV

将用户提供的信息整理为待确认活动；只有用户确认具体内容和条目后，才生成最终 CSV，由用户手动导入。

## 背景与输入

- 默认学校为中南大学，用户本轮或会话指定的学校优先；不由学校推断用户院系、年级、学历或参赛资格。
- 支持单个或多个活动：名称片段、简称、自然语言、通知正文、链接或可读取的截图、文件。先拆分条目并编号，不要求用户逐一填写表单。
- 本地网页项目目前位于 `D:/Study250711/coding_projects/campus_competetion`。字段及导入约束见 [references/csv-contract.md](references/csv-contract.md)，生成文件前读取。若项目可用且导入逻辑已变化，以实际代码为准并说明与约定的差异。

## 搜索与核验

1. 信息足以识别活动时直接搜索补全；只有同名赛事、学校、年份、届次或赛道歧义会影响结果时，才提出针对性问题。可以继续处理批次中其他明确的条目。
2. 优先官方赛事网站、主办方通知、中南大学及相关院系通知；第三方信息仅作线索或明确标注其性质。打开并读取原始通知，不把搜索摘要当作已核验事实。
3. 明确通知对应的年份、届次、赛道和阶段；不得将往届日期当作本届日期。“今年”按当前日期解析；未指定年份且无法确定目标届次时询问，不自动选最新搜索结果。
4. 区分校内报名、校内选拔和全国赛事的截止时间。针对用户实际要报名的阶段填写日期，备注其他阶段及其来源。来源冲突时展示冲突，优先检查是否属于不同阶段或有官方更正，不能无说明地择一。
5. 查不到的非关键字段留空，并在预览列为“未查到/待核实”。不编造日期、地点、资格、报名链接或主办方。无法确认活动身份的条目暂缓；可保留用户明确提供的事实，但标为“用户提供”，不得伪称已联网核实。
6. 每个活动提供可点击的原始来源链接、来源标题或发布机构，并说明支持哪些关键信息。主要通知进入 `source_url`，其他必要来源及冲突说明进入 `notes`。只有实际读取并核对的信息才标为已核验；搜索不可用或页面无法读取时说明限制。

## 合并与个人字段

- 先判断用户需要首次清单、与旧清单合并还是仅新增条目的 CSV。有旧数据时请用户提供网页导出的最新 CSV，以其为基线合并；不能用项目演示数据替代真实旧记录。
- 保持旧记录 ID、个人意向、优先级、标签及备注；修改已存在活动时只更新此次确认的字段，追加来源备注时保留原文。默认不删除任何旧活动。
- 结合名称、届次、主办方和阶段判断重复。来源相同不必然是同一活动；同名的不同届次也不必然重复。疑似重复列入确认，不静默覆盖。
- 新活动默认 `participation_decision=maybe`、`priority=中`。分类与标签采用有依据的客观描述，不自动添加“高含金量”等评价。用户明确提供的个人偏好优先。
- 不将“确定参加”当作完成报名，不替用户报名。
- 没有旧 CSV 时可准备仅含新增条目的清单；在确认预览及最终交付中说明：网页导入会替换整个列表，直接导入此文件会移除未包含的旧活动。用户确认新增文件不等于授权清空网页；本 skill 不执行网页导入。

## 确认关口

搜索、解析、去重和预览可以直接进行；生成最终 CSV 前必须获得用户对具体预览的确认。

- 按编号展示每条活动的拟录入名称、届次/阶段、主办方、分类/标签、简介、报名及活动日期、地点、资格、状态、个人意向、优先级、备注和核验来源。空字段可合并列为缺失项；内部 ID 可省略。
- 批量先给概览表，再列每条的来源、缺失或冲突；允许“全部确认”“只录入第 1、3 项”或逐条修改。
- 说明交付的是完整合并清单还是仅新增清单，给出新增、更新、保留、暂缓条目数。对已有活动展示具体变更。
- 网页状态字段不能表示“未知/未开始”。无法确定或无法准确表示时，展示限制并请用户决定暂缓该条或明确选用可用状态；不得利用导入默认值把未知活动标为报名中。
- 用户泛泛地说“帮我录入”不构成对未展示内容的确认。说明此处确认来自本 skill 的“生成文件前确认”规则及用户已设定的工作流程。
- 只输出确认范围内的新增或修改；合并清单中的其余旧记录原样保留。实质修改已确认字段，或合并基线发生变化时，展示差异并重新确认受影响内容。纯转义、编码和 ID 生成无需再次确认。

## 生成与交付

- 按字段约定用标准 CSV 库生成 UTF-8 BOM 文件，日期按 `YYYY-MM-DD`；多标签以英文分号分隔。可在工作区输出目录保存文件；不覆盖原始导出或备份。
- 使用 CSV 解析器回读文件，检查表头、列数、记录数、ID 与来源 URL 唯一性、枚举、有效日历日期及明显的日期先后矛盾。检查每个待录入活动与确认内容一致，合并时确认无非预期删除或个人字段改变。
- 发现导入约束与真实信息冲突时，停止生成不兼容的最终文件并解释具体条目；不能伪造来源或改写事实来通过校验。
- 交付可点击的 CSV 文件链接，说明条目数量及清单类型，并提醒用户手动导入。仅报告“文件已生成”，不能声称已录入网页或已报名。

## 典型请求

- “把今年蓝桥杯加进去”：默认查中南大学相关通知，核实具体届次与报名阶段，预览后等待确认。
- “这段通知里的三个活动都加进去”：拆分三项分别核验，允许仅确认其中两项。
- “这是旧清单，再加这个比赛”：保留旧记录及个人字段，确认新增项后输出完整合并清单。
